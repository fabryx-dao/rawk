## What is Rawk?

Rawk is a sealed, lichen-green Linux computer that:
- Runs OpenClaw — a powerful AI assistant framework
- Connects via WhatsApp, Telegram, or web chat
- Executes commands, browses the web, manages files
- Runs entirely on your local network (no cloud dependency except AI inference)
- Costs $99 and is designed to be wrecked and rebuilt

Think of it as AI in a rock. Mineral Intelligence™.
